# GitPulse 0.32

**Shipped** on main (M44 / product 0.32.0) on 2026-09-01. No `v*` tag.

PR Conversation 可以把 Draft PR 标成 ready for review。

0.32 证明日用 GitHub 用户能在 Windows 应用里结束 create-time draft，不必再开浏览器。不证明 convert-to-draft，不重做 Update Branch。

## 产品句

打开已登录的 Windows GitPulse，进入一条 **open、draft、未合并** 的 PR Conversation，点 **Ready for review**。应用调用 `POST /repos/{owner}/{repo}/pulls/{number}/ready_for_review`。201 后刷新该 PR（draft 消失）；403/422 留在本页。已在 origin/main。MergeStatus 已有 “Draft — needs to be marked ready for review” 文案，本 minor 补上对应写操作。

```
Tests         ← 无头断言 201 / 403 / 422

```

不新建项目。不破坏 `IGitHubReposApi` 既有方法。

## 解决方案

在 `IGitHubReposApi` 增加 `POST /repos/{owner}/{repo}/pulls/{number}/ready_for_review`。Conversation 在 PR `state=open`、`draft`、未合并时显示 Ready for review。成功（201）后重新 GET pull；403/422 留在本页（与 Update Branch / Fork 同一模式）。无 body。不调用 convert_to_draft。
