# GitPulse 0.31

**Shipped** on main (M43 / product 0.31.0). No `v*` tag.

PR Conversation 可以把落后的 head 分支更新到 base。

0.31 证明日用 GitHub 用户能在 Windows 应用里点 Update branch，不必再开浏览器。不证明 draft ↔ ready，不证明 compare / behind 计数。

## 产品句

打开已登录的 Windows GitPulse，进入一条 **open、未合并** 的 PR Conversation，点 **Update branch**。应用调用 `PUT /repos/{owner}/{repo}/pulls/{number}/update-branch`（可选 `expected_head_sha` 为当前 head SHA）。202 后刷新该 PR；403/422 留在本页。已在 origin/main。


不新建项目。不破坏 `IGitHubReposApi` 既有方法。

## 解决方案

在 `IGitHubReposApi` 增加 `PUT /repos/{owner}/{repo}/pulls/{number}/update-branch`。Conversation 在 PR `state=open` 且未合并时显示 Update branch。成功（202）后重新 GET pull；403/422 留在本页（与 Fork / workflow_dispatch 同一模式）。可选 body 带当前 `Head.Sha`。不调用 compare，不重做 Gate Rollup。

## 范围

### 必须有

1. **新 RestAPI 方法。** `UpdatePullRequestBranch` 在 GitHubApi 上，而不是复用 merge。
2. **能点。** 打开一条 open 未合并 PR，Conversation 有 Update branch。
3. **错误留在页上。** 403/422 不导航走。
4. **测试。** CiLib 覆盖成功刷新与 403/422。不跑 live-PAT。

### 明确砍掉

- ready-for-review / convert-to-draft
- compare / behind_by 计数
- auto-merge / rebase-update
- cancel workflow / artifacts
- created inbox / SSH clone URL
- 重开 ADR-004/005/012/013/014
- 重做 Search Inbox / Gate Rollup / list-cycle
- 打 `v*` tag / GitHub Release

## 风险

- **做成 compare。** 禁止 `GET .../compare/{base}...{head}`，禁止 behind 计数。
- **做成 ready-for-review。** MergeStatus 已有 draft 文案也不升到本 minor。
- **重做 Gate Rollup。** 禁止。Update branch 不是 checks 汇总。
- **打 tag。** 禁止。MinVer 停在 v0.7.0 直到人 cut。
