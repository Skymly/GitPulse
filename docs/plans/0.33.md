# GitPulse 0.33

PR Conversation 可以把 open 非 Draft PR 转成 draft。

0.33 证明日用 GitHub 用户能在 Windows 应用里把一条已公开的 PR 转回 draft，不必再开浏览器。不重做 Ready for review，不重做 Update Branch。

## 产品句

打开已登录的 Windows GitPulse，进入一条 **open、非 draft、未合并** 的 PR Conversation，点 **Convert to draft**。应用调用 `POST /repos/{owner}/{repo}/pulls/{number}/convert_to_draft`。201 后刷新该 PR（draft 出现）；403/422 留在本页。当前 origin/main 没有该按钮、也没有该方法。Ready for review（0.32）只服务 draft，本 minor 补上对偶写操作。


不新建项目。不破坏 `IGitHubReposApi` 既有方法。

## 解决方案

在 `IGitHubReposApi` 增加 `POST /repos/{owner}/{repo}/pulls/{number}/convert_to_draft`。Conversation 在 PR `state=open`、非 `draft`、未合并时显示 Convert to draft。成功（201）后重新 GET pull；403/422 留在本页（与 Ready for review / Update Branch / Fork 同一模式）。无 body。不调用 ready_for_review。

3. **错误留在页上。** 403/422 不导航走。
