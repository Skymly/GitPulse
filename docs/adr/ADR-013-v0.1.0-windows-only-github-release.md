# ADR-013: v0.1.0 仅 Windows GitHub Release（Android APK 延后）

| 字段 | 值 |
|------|-----|
| **状态** | Superseded by [ADR-014](ADR-014-android-emulator-ui-smoke-and-apk-release.md)（v0.1.0 史实仍适用） |
| **日期** | 2026-07-29 |
| **关联 Issue** | [#54](https://github.com/Skymly/GitPulse/issues/54)、[#58](https://github.com/Skymly/GitPulse/issues/58) |
| **取代** | [ADR-012](ADR-012-v0.1.0-github-release-distribution.md) |

## 背景

ADR-012 规定 v0.1.0 同时挂 Windows publish zip 与 CI 签名 Android APK，且 cut 前须完成 Android 侧载冒烟。流水线（#56 / #57）已按该契约落地；但维护者暂无合适 Android 真机做侧载验收，若仍强制双产物，要么未经冒烟挂 APK，要么无法打公开 tag。

Windows FlaUI UI 冒烟已可重复跑通；Android 仍仅有 `CiAndroid` 编译门禁，无 UI 自动化。

## 决策

- **取代 ADR-012**：v0.1.0（及当前 M12 cut）的公开发版范围为 **仅 Windows**。
- **分发渠道**：仍仅 **GitHub Releases**（`v*` tag）；不上商店。
- **v0.1.0 Release Artifact**：**仅** Windows self-contained publish **目录 zip**。Windows **不做** Authenticode。
- **Android**：签名 APK 流水线目标（`PublishAndroid*`）与 Secrets 契约**保留**，供有设备后再发；**不**作为 `v0.1.0` / 当前 `Release` tag job 的必挂产物。Android 公开发版延后到有侧载冒烟条件之后（另开里程碑或后续 patch，不阻塞 v0.1.0）。
- **cut 门槛（v0.1.0）**：Windows 运行 + PAT；一等公民页短冒烟（可用本机 FlaUI UITests）；CHANGELOG 将 `[Unreleased]` 收成 `[0.1.0]`。**不要求** Android 侧载冒烟。
- **明确不做（v0.1.0）**：商店上架、Win 码签、AAB、GitHub App OAuth、Android 出应用通知、iOS / MacCatalyst、新功能 / UX 精修；以及 **公开发 Android APK**。

## 后果

- **正面**：可在无 Android 设备的情况下完成首发；与「Windows 优先」（ADR-005）一致。
- **正面**：Android 签名能力不丢弃，日后加回 tag 附件无需重做 keystore 契约。
- **负面**：Android 用户须等待后续版本；Release 页不再保证有 APK。
- **文档 / 流水线**：ROADMAP、DEVELOPMENT、CONTEXT、#58 与 `release` job 改为 Win-only；Nuke `Release` 不再依赖 `PublishAndroidVerify`。
